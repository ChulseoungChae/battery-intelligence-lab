# 사용후 배터리 ESS 전처리

GW1–GW4를 하나의 ESS(A), GW5–GW8을 다른 ESS(B)로 두고, 2026-03-01부터 2026-06-30까지 DC-DC로 서로 충·방전한 로그를 정리한다. 전류 양수는 그 GW로 들어오는 충전이다.

원본 CSV는 `/data1/ess_data/battery_data`에 있다. 전처리 결과는 이 폴더 기준 `../../ess_data/preproced_data`이며, 절대 경로는 `/data1/github_cschae/ess_data/preproced_data`이다. 결과 폴더명은 `preproced_data`를 그대로 쓴다. 용량이 커서 git에는 올리지 않는다.

## 실행

```bash
pip install -r requirements.txt
python preprocess.py
```

원본이나 출력 위치를 바꿀 때:

```bash
python preprocess.py --raw /data1/ess_data/battery_data --out ../../ess_data/preproced_data
```

## 처리 내용

컬럼 이름이 깨진 파일이 있어 CSV는 헤더 문자열이 아니라 열 위치로 읽는다. 순서는 시각, 팩 전류, 팩 전압, 셀 전압 100, 셀 저항 100, 모듈 온도 20, 냉각온도 2이다. CO2, TVOC, 내부온도 4개, 습도 4개는 원본이 전부 0이라 저장하지 않는다. `Date_Time` 앞의 작은따옴표는 제거한다.

시각은 30초 격자로 맞춘다. 1초로 쌓인 `GW1_20260301`, `GW2_20260301`, `GW5_20260301`은 30초 평균이다. 초가 없고 같은 분이 두 번 찍힌 `GW1_20260313`, `GW1_20260425`, `GW4_20260426`은 파일 순서대로 0초와 30초를 붙인다. 비어 있는 날은 만들지 않는다.

아래 파일은 `clean`에 넣지 않는다.

- 파일명과 내용 날짜가 다른 3개. 내용은 2024년이다. `GW4_20260625`, `GW7_20260510`, `GW8_20260301`.
- 시각만 다르고 측정값이 같은 복제 27개. 같은 GW면 가장 이른 날짜만 남긴다. GW가 섞이면 어느 쪽이 원본인지 알 수 없어 그 묶음은 전부 제외한다. GW6과 GW7의 3/1, 3/7, 3/8, 3/9와 GW7 3/22가 여기에 해당한다. 목록은 `reports/duplicate_groups.csv`에 있다.
- `GW6_20260406`은 `GW6_20260402`와 대부분 겹치지만 일부 행의 전류·전압이 달라 유지했다.

센서 값은 지우지 않고 결측으로 바꾼 뒤 플래그를 남긴다.

- 냉각온도는 -40 미만이거나 1000 초과면 결측. ESS A는 거의 전부 결측이고, ESS B는 유효하다.
- 셀 온도는 -40 미만이면 결측.
- 한 파일에서 셀 전압이 80% 이상 0이면 그 슬롯은 비활성이다. 대부분 `vol_m2_c20`, `vol_m3_c20`이다. 전압·저항을 결측으로 두고 `reports/inactive_slots.csv`에 기록한다.
- 활성 슬롯의 셀 전압 0은 측정 끊김이라 결측으로 두고 `flag_cell_zero`를 단다. 0보다 크고 2.5V 미만은 값을 유지하고 `flag_low_cell`만 단다.
- 팩 전압 200V 미만은 결측, `flag_pack_dropout`.
- 활성 셀 전압의 합과 팩 전압 차이가 5V를 넘으면 `flag_vsum_mismatch`. GW2는 이런 행이 약 72%라, 이 플래그만으로 행을 지우면 안 된다. 랙마다 셀 전압 합이 팩 전압과 일정하게 어긋나 있다.
- 30초 구간 안에 절대값 20A를 넘는 전류가 있으면 `flag_current_spike`. 해당 구간은 GW1뿐이고, 최댓값은 340A이다.
- GW 전체를 시간순으로 잇고, 직전 샘플과 10분을 넘으면 `flag_gap`과 `gap_before_s`를 단다. 이 구간에서는 전류를 적산하지 않는다. 시험하지 않은 날도 다음 샘플에 이 플래그가 붙는다.

## 출력

| 경로 | 내용 |
|---|---|
| `clean/GW1.parquet` … `GW8.parquet` | GW별 30초 시계열. `ess`는 A 또는 B |
| `aligned/ess_pair.parquet` | 8개 GW가 모두 있는 시각. 랙 전류 합 `I_A`/`I_B`, 평균 전압, 전력 `P_A`/`P_B`(W) |
| `reports/file_manifest.csv` | 파일별 kept / duplicate / quarantine |
| `reports/duplicate_groups.csv` | 복제 묶음과 유지·제외 |
| `reports/inactive_slots.csv` | 파일별 비활성 셀 슬롯 |
| `reports/summary.json` | 행 수와 정합 결과 |

`clean`의 셀 열 이름은 `vol_m{모듈}_c{셀}`, `res_m{모듈}_c{셀}`, `temp_m{모듈}_s{센서}`이다. 모듈은 1–5, 셀은 1–20, 온도 센서는 1–4이다.

## 결과

원본 505개 중 475개를 남겼다. 복제 27개, 날짜 불일치 3개를 제외했다. 남은 행은 1,291,741행이다.

8개가 겹치는 시각은 108,360행이고 2026-03-06 15:26부터 2026-06-29 23:59까지다. 이 구간의 전력 상관은 -0.995이고, 전류가 흐를 때 두 랙의 부호가 반대인 비율은 99.98%이다.

GW별 `flag_gap`은 21–29개다. 가장 긴 공백은 GW7의 약 288시간이다.
